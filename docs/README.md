# Documentation

This directory contains conceptual and operational documentation for the AI Blueprint Model.

- `blueprint-anatomy.md`: anatomy of a blueprint, constraints and normative language, required vs optional sections, and implementation guidance.
- `execution-modes.md`: operational workflows for blueprints — Manual, Human-in-the-Loop, Semi-automated, and Operational — including expected rigidity, validation expectations, and AI freedom levels.
- `versioning.md`: semantic versioning conventions for blueprints, including Patch, Minor, and Major change guidance.
