# outputs.md guidance

## Purpose

Describe the artifact or deliverable the blueprint should produce.

## Recommended sections

- primary output
- format expectations
- delivery constraints
- optional variants

## Authoring guidance

- define what success looks like in concrete terms
- describe format and structure without over-specifying implementation details
- note variant outputs only when they are genuinely useful

## Common pitfalls

- repeating input requirements instead of output expectations
- leaving format assumptions implicit
