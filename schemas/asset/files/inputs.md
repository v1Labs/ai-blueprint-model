# inputs.md guidance

## Purpose

Define the source material, context, and constraints available before asset generation begins.

## Recommended sections

- required source inputs
- optional enrichment inputs
- audience or channel context
- missing-information handling

## Authoring guidance

- define the upstream information the asset depends on
- distinguish source facts from downstream content-generation rules
- note channel-specific inputs when they materially change output

## Common pitfalls

- using `inputs.md` to describe the output instead of the source context
- hiding critical context dependencies in unrelated files
