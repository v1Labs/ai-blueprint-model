# evaluations.md guidance

## Purpose

Translate the asset blueprint into reviewable quality and compliance checks.

## Recommended sections

- structural checks
- content-grounding checks
- style-consistency checks
- channel-fit or usability checks

## Authoring guidance

- evaluate both content fidelity and style fidelity
- map review criteria back to `outputs.md`, `constraints.md`, `content.md`, and `style.md`
- document common failure modes that reviewers should look for

## Common pitfalls

- judging style without defining style expectations
- introducing evaluation criteria that are not supported by the blueprint files
