# content.md guidance

## Purpose

Define how the asset's content should be sourced, grounded, and generated.

## Recommended sections

- preferred source hierarchy
- trusted systems or references
- fallback generation behavior
- factual grounding rules
- prohibited invention or speculation

## Authoring guidance

- declare the preferred order of source material clearly
- explain what the model should do when information is incomplete
- separate source-of-truth rules from visual presentation guidance
- specify where generated filler is acceptable and where it is not

## Common pitfalls

- mixing visual direction into content sourcing guidance
- failing to document how missing facts should be handled
