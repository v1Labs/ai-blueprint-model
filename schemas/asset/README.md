# asset schema

The `asset` schema extends `basic` for richer artifact-generation blueprints.

## Expected blueprint files

Required:
- `README.md`
- `inputs.md`
- `outputs.md`
- `constraints.md`
- `components.md`
- `evaluations.md`
- `examples/` (directory with one or more markdown examples)

## Scope

Use `asset` when the blueprint needs reusable components, concrete examples, and explicit evaluation guidance.
