# GTM One-Pager Blueprint (Example)

## Intent

Generate a concise, evidence-backed GTM one-pager that aligns product, marketing, and sales on launch execution.

## Constraints

### MUST

1. Output MUST include sections in this exact order:
   - Product Summary
   - Target Customer
   - Core Value Proposition
   - Launch Motion
   - Risks and Mitigations
   - Success Metrics
2. Claims about outcomes MUST be tied to provided inputs.
3. Output MUST not include unverifiable superlatives.
4. Total length MUST be between 350 and 700 words.

### SHOULD

- Output SHOULD use direct, low-jargon language.
- Output SHOULD use bullet lists for execution actions.
- Output SHOULD keep to one primary message and up to three supporting points.

## Components

### Component A: Product Summary
Inputs: product problem, solution, differentiators
Output: 3-5 sentence summary

### Component B: Target Customer
Inputs: ICP profile, segment priorities
Output: primary segment + buying trigger + disqualifiers

### Component C: Launch Motion
Inputs: channels, launch window, dependencies
Output: phased launch steps with owners

## Example Input Packet

- Product: API observability assistant for platform teams
- ICP: B2B SaaS companies (100-1000 employees)
- Core pain: prolonged incident resolution time
- Differentiator: AI-assisted root-cause hypothesis from telemetry traces
- Evidence: pilot reduced median triage time by 28%
