# Content

## Preferred source hierarchy

1. approved announcement facts
2. audience-specific context from the request
3. prior approved messaging fragments

## Fallback behavior

- If a key fact is missing, the draft SHOULD ask for it or leave a neutral placeholder.
- The asset MUST NOT invent performance claims, launch dates, or customer results.

## Grounding guidance

- Prefer source language that can be traced back to the announcement.
- Keep channel variants aligned to the same core message.
